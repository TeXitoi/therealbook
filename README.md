# The Real Book Sheet Index

## Presentation

This site provide an index for the original Real Books, findable as
PDF. The PDFs are not distributed by this site, but fetched
elsewhere. To be used for historical and educational purpose. Please
buy the original sheets if you use them.

## Documentation

Type a title or an artist in the search input. You can select the
sheet with the mouse or the keyboard arrows and enter. Escape to go
back to the search input. Selecting an already selected song open the
next alternative score. You can also directly select the wanted
alternative score in the "Alternatives" section.

When you select a score, the URL change. This allow to share a tune,
or to go back to the tune on page reload.
